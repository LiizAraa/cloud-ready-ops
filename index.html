Proyecto Cloud-Ready Ops

Diseño y configuración de una arquitectura web de tres capas en AWS, utilizando una VPC personalizada y segmentación de red.

La infraestructura incluye una subred pública para el servidor web y una subred privada para la base de datos.

Tecnologías utilizadas: AWS EC2, VPC, Security Groups, Internet Gateway, Ubuntu Server, Nginx, MySQL y SQL.

Arquitectura implementada

El servidor web se encuentra expuesto mediante HTTP en el puerto 80, mientras que la base de datos permanece aislada en una subred privada.

La comunicación entre el servidor Web y la base de datos se realiza mediante la red privada y el puerto MySQL 3306.
